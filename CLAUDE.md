# Agent Instructions

## Commit and push

- Commit and push finished changes directly to `main` on `origin` without asking for permission first. Pull requests are not required; create one only if the user explicitly requests it.
- Skip committing or pushing only when the user explicitly says not to.
- Stage only changes belonging to the current task. Preserve unrelated work.
- Include the commit's short hash and subject in the final summary.
- If a commit or push fails, fix the issue and retry. If it stays blocked, report the blocker and any commit hash already created.
